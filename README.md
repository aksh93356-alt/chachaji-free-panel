# CJH Free VPS Panel

One-click installer for Docker-based free VPS management panel.

## 🚀 One-Click Installation Command
Run this command on your fresh Ubuntu VPS:

```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git](https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git) vps-panel && cd vps-panel && chmod +x setup.sh && sudo bash setup.sh
